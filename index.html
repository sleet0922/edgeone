01 / 它做了什么

三步走完一次发布

01

推送即触发

每次提交到生产分支，平台自动拉取最新代码，不用打包、不用手动上传压缩包。

02

构建产物可预期

构建脚本只做一件事：把静态文件复制进 dist/。没有插件、没有隐式依赖，失败率接近零。

03

全球边缘分发

产物发布到全球可用区（含中国大陆）的节点，访问就近命中，首屏更快。

03 / 上线之后

三件事确认部署成功

  • ✓

    打开平台分配的域名

    能看到这一页，说明静态资源已经分发到边缘节点。

  • ✓

    确认版本是最新提交

    页面底部会显示仓库与分支，和 GitHub 上最后一次提交对得上。

  • ✓

    推一个空提交再验证

    git commit --allow-empty -m "chore: 触发部署"，控制台应自动出现新构建。

这个页面本身就是产物

它没有框架、没有打包器，只有 HTML、CSS 和一点原生 JS —— 用来验证「push → build → 上线」这条链路是否通畅。
